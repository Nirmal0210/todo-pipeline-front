# Todo Pipeline - CI/CD Demo

A full-stack todo application demonstrating modern CI/CD practices with automated testing, containerization, and cloud deployment.

## 🚀 Tech Stack

- **Frontend/Backend**: SvelteKit
- **Database**: PostgreSQL with Prisma ORM
- **Containerization**: Docker
- **Deployment**: Fly.io
- **CI/CD**: GitHub Actions

## 📦 Features

- ✅ Automated build and deployment pipeline
- ✅ Docker containerization for consistent environments
- ✅ Database migrations with Prisma
- ✅ Secure environment variable management
- ✅ Zero-downtime deployments
- ✅ PostgreSQL database integration

## 🔄 CI/CD Pipeline

This project automatically:
1. Builds Docker container on every push
2. Generates Prisma client
3. Runs tests (if configured)
4. Deploys to Fly.io on successful build
5. Handles database migrations
